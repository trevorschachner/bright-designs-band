# Architecture decision records

One file per decision, numbered in order (`0001-short-title.md`). Each records the context, the decision, and its consequences.

Rules:

- An accepted ADR is never edited, apart from fixing typos or adding a "Superseded by" line.
- To change a decision, write a new ADR. Mark the old one superseded and link forward to the new one; the new one links back.
- Keep them short. If it is not a decision with a "why", it belongs in `CONTEXT.md` or `docs/`.
